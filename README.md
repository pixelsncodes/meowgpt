# 🐱 MeowGPT

The world's most useless AI chatbot. Ask it anything — about life, love, the universe — and receive an expertly crafted reply: "meow".

**Live at:** [meowgpt.app](https://meowgpt.app) ← update once deployed

## Features

- 🗨️ Chat interface that responds exclusively in meows (20+ variants)
- 🎤 Voice mode with a cute breathing blob (doesn't actually use your mic)
- ⏱️ Authentic AI typing indicator that pretends to think
- 📱 Fully responsive — works on desktop, tablet, and mobile
- 🔒 No data stored, no accounts, no tracking

## Tech

Single-file HTML. No build step. No dependencies. Just open and meow.

## Running locally

Open `index.html` in a browser. That's it.
